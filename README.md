# Tanvi — personal site v2

This is a redesigned version of the current GitHub Pages portfolio.

## What changed

- New opening: **"I'm a full-time problem solver."**
- Minimal fixed navigation: ME / WORK / PEOPLE / PLAY / CONTACT
- One continuous narrative instead of a resume-style portfolio
- Work is intentionally high-level and avoids confidential/internal Barclays project details
- People is the emotional centre of the site
- Direct link to Nikhil D'Souza's official YouTube upload of **People**
- Tennis, puzzles, photography and lifestyle are treated as personality, not achievement labels
- Existing `assets/profile.jpg` is reused
- Additional photo slots are included for your own photographs

## Add your photographs

Put these into the existing `/assets` folder:

- `me-01.jpg`
- `me-02.jpg`
- `me-03.jpg`
- `people-01.jpg`
- `people-02.jpg`
- `people-03.jpg`
- `tennis.jpg`

The page will still work if these files are absent; the cards simply show their editorial placeholders.

## Files

Replace your current:
- `index.html`
- `style.css`
- `script.js`

with the files in this package.

No framework or build step is required.

## Important

Before publishing, proofread every factual statement and replace any placeholder photographs.
